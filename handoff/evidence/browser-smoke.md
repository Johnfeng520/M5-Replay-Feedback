# 本机浏览器验证记录 · 2026-11-02

环境：Windows，本地 Node 服务 3001 直接提供生产构建的网页。测试内容/账号均为虚构演示数据，运行库不随包分发。

已实际操作并观察结果：

1. creator@example.test 登录后显示本人活动；从示例一创建新的真实草稿。
2. 改写入口正文，点击保存，服务器 revision 从 2 增至 3。
3. 点击检查得到“检查结果：通过”；发布显示“版本 1 已发布”并生成试玩链接。
4. 打开刚发布版本，开始新会话；没有钥匙时“打开档案室”禁用。网页正文显示刚保存的文字。
5. 查看桌面获得钥匙/线索，在步骤1保存进度；原会话返回活动室推进到步骤2。
6. 从步骤1存档恢复，页面显示步骤0、桌面线索、新会话ID与原版v1；原会话保留，见 browser-restore.png。
7. 刷新后继续恢复分支：返回活动室→打开档案室→按线索查找，最终显示“本故事到此结束”，钥匙已消耗。
8. 从示例二创建另一活动，使用同一检查/发布流程通过并发布v1。

本记录是本机操作证据；没有把它记为其他成员电脑验收、真实需求访谈或公网部署验证。v2发布后旧版恢复、两个玩家隔离与事务故障由独立集成自动化测试验证。
